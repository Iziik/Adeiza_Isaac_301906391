# MIT 8103 Advanced Database Systems Continous Assesment

This step-by-step guide shows the MIT 8103 continuous assessment. Using a Banking case study for all five portfolio activities, and documented evidence of my work throughout the project phase.

# Banking System

The portfolio uses fictional records for Banking accounts and transactions.

## Case Study

Case study statement | Item	Description 
| --- | --- |
| Organisation / scenario |	Meridian Trust Bank, a simulated retail bank with four branches and mobile, web, ATM and POS channels
| Nature of the business |	Retail banking: accounts, deposits, withdrawals, transfers and reversals, with a permanent record of every money movement
| Users of the database |  Tellers and branch managers, operations staff, auditors |
| Major data stored	| Customers and KYC status, branches, staff, account types, accounts and balances, transactions, ledger entries, audit trail; customer profiles and transaction events (NoSQL) |
| Key operations	| Open account, deposit, withdraw, transfer, reverse, statement, balance reconciliation, fraud detection 

## What is Included

The assessment is worth 40 marks. This Submissiom includes a practical database work and a short summary.

| Component | Required work and evidence | Marks |
| --- | --- | ---: |
| Portfolio 1: Database Design and Modelling | Case-study description, ER diagram, relational schema, keys, constraints and normalisation explanation | 7 |
| Portfolio 2: Query Processing and Optimisation | SQL queries, results, execution plans, optimisation evidence and a brief performance analysis | 7 |
| Portfolio 3: Transactions and Concurrency | Commit, rollback, isolation and a concurrency issue or control mechanism, supported by outputs or screenshots | 7 |
| Portfolio 4: NoSQL and Advanced Data Models | A NoSQL model for the same case study, implementation evidence and an explanation of suitability | 7 |
| Portfolio 5: Distributed and Cloud Database Exercise | A case-related discussion or setup covering relevant concepts such as replication, sharding, availability, consistency or deployment | 6 |
| Final documentation | A 2–3-page summary covering the activities, selected case study, GitHub link, evidence, individual reflection, references and AI-use declaration where applicable | 6 |
| Total | | 40 |
